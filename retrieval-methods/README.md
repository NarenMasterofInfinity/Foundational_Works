# Unit 01 · Retrieval Methods

Open [index.html](index.html), or enter from the [library](../index.html). The page embeds its styles, content, calculations and diagrams; it needs no network connection except when you follow external references.

The guide has an overview, a historical timeline, thirteen retrieval/system families, a separate evaluation tab, and an annotated reading room. The categories distinguish models, representations, execution indexes and orchestration rather than presenting all search techniques as interchangeable algorithms.

The **21 October teaching revision** reviews every chapter and all 52 method notes. Chapters now start with an everyday problem, a three-step diagram and definitions, then an experiment. Each method note explains why the idea exists and gives a concrete mental example. Formal terminology, symbol definitions and equations live in a separate optional disclosure; definitions precede equations. The timeline also describes the problem solved before naming the landmark. `src/teaching.py` holds this teaching layer, and the build fails if any method lacks it.

Fourteen labs cover Boolean expression parsing with phrases and metadata filters, TF–IDF cosine and dot products, BM25 and Dirichlet query likelihood, query expansion, dense-vector geometry, sparse expansion/pruning, MaxSim, IVF-style probing, candidate-limited reranking, rank/score fusion and MMR, graph traversal, visual evidence retention, scripted agentic search, and reorderable evaluation.

The browser calculates the advertised arithmetic. Embeddings, sparse weights, token-similarity matrices, neural reranker scores and semantic scores are explicitly synthetic teaching fixtures. No neural model, LLM or external API runs. Graph/visual/agent demonstrations are deterministic schematics, not implementations of GraphRAG, ColPali or Self-RAG. The demonstrations are not performance benchmarks.

The shared eight-document collection is synthetic. Its titles are labels; lexical labs index only the shown bodies, using lowercase alphanumeric tokens without stemming or stopword removal. Five documents have positive relevance grades for the fixed evaluation query, “solar battery storage”. The evaluation lab separates single-query RR from MRR, relevance recall from ANN recall, and states its nDCG gain convention and AP prefix denominator.

The Boolean result now displays **every searched body, highlighted query-token occurrences and a KEEP/SKIP decision**. It never supplies relevance scores. D1’s display title uses “Batteries”, but its body contains literal `battery` twice; this is why it matches. The shared corpus has no body token `batteries`, so a strict query for it returns no matches. A separate two-sentence fixture contrasts literal matching with one explicitly enabled dictionary mapping, `batteries → battery`, applied to both query and bodies. It does not change the shared corpus or claim to implement a general stemmer. Unquoted inputs that split into multiple indexed tokens must use explicit operators or a quoted phrase.

Candidate selection for the reranking and fusion demos now excludes zero-score BM25 documents. Raising a word-only budget to eight returns only seven matching documents; D2 remains absent. A selectable hybrid source can add D2 through the explicitly synthetic meaning list. A scorer over the full collection, such as the evaluation starting order, still includes zero-score documents when that is the stated task.

Expandable calculation traces cover TF–IDF products and numerical vector lengths, BM25 token contributions, smoothed word probabilities, all IVF point distances, and rank-by-rank evaluation credit. The dense-map axes use equal coordinate scales. BM25 computes the repetition multiplier before applying IDF, avoiding a floating-point artifact that could otherwise break ties at `k₁=0`.

The original sources were checked on **20 October 2026**, with two teaching references added on **21 October**: the Stanford text’s word-form explanation and Google’s vector-similarity guide. The reading room now contains 47 papers, surveys, chapters and guides. The Stanford textbook, Sentence Transformers’ retrieve-and-rerank guide and Google’s worked similarity explanation informed the progression from concrete question to formal calculation. Historical milestone dates distinguish first preprints, publications and approximate development periods. Recent work includes Qwen3 Embedding, DIVER and BRIGHT-Pro; no universal or permanent state-of-the-art winner is claimed.

Tabs support arrow keys and Home/End, links use stable anchors (such as `#timeline`, `#fusion`, `#ranking`, `#sources`), mobile has a chapter menu, and the print button expands all families and method notes. Sliders, forms and controls have labels; result regions announce changes. The page respects reduced-motion preferences.

Rebuild: `python3 src/build.py` from this folder, or `python3 retrieval-methods/src/build.py` from the repository root.
