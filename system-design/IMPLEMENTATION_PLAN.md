# Complete-edition production plan

The requested scope is all 22 units, in one continuous implementation pass. Preserve the original syllabus and existing visual language.

1. **Editorial model:** replace Unit-1-only assumptions with a content-driven production registry. Keep chapter IDs and all prior links stable. A chapter becomes available only when its actual lesson, figures, worked mechanism, and references exist.
2. **Foundations and LLD:** produce Units 2–8, including quantitative workload reasoning, protocol and concurrency traces, payment refactoring, individual pattern mechanisms, lifetimes, domain boundaries, and payment API histories.
3. **Data and distributed systems:** produce Units 9–17, including storage internals, transaction anomalies, cache races, partitioning, ingestion, consistency histories, Raft, outbox/sagas, overload, and recovery.
4. **Production:** produce Units 18–21, including trust boundaries, tenant enforcement, telemetry diagnosis, safe releases, cost assumptions, and falsifiable validation.
5. **Complete designs:** produce all twelve Unit 22 case studies with all 22 mandatory sections, explicit numerical assumptions, APIs, schemas, LLD, HLD, failures, security, operations, costs, alternatives, evolution, and an implementation challenge.
6. **Assessment and assembly:** add eleven reasoning questions and separate explained answers for every unit. Extend glossary, formula/pattern/diagram indexes, reading paths, and source bibliography. Remove stale planned-state copy only after production validation.
7. **Verification:** check syllabus coverage, actual prose and figure presence, case-study section completeness, calculations and runnable examples, offline navigation, mobile layouts, search, accessibility basics, and print output. Generate a complete PDF plus retain the foundations export as a separately scoped artifact.

The final manifest must distinguish produced content from review evidence. Passing a coverage check is not a claim that every production guarantee has been formally proved or that illustrative infrastructure sizes are measured benchmarks.

## Completed

All seven production steps are implemented. The final edition contains all 22 units and 99 chapters, 575 original figures, all twelve 22-section designs, 26 individual pattern treatments, thirteen workbenches, and 242 questions with separate explained answers. The generated manifest records the exact artifacts. The complete tagged PDF and its source identity are recorded in [release.json](release.json); the original foundations PDF is retained. Final build, executable, browser, responsive, offline, SVG, print, and PDF checks are recorded in [QA.md](QA.md).
